# نشر موقع بيتزاستو على GitHub Pages

هذه الحزمة تحتوي على صفحة واحدة للعملاء والإدارة:

- `index.html`: صفحة الطلب، وبداخلها نافذة إدارة مخفية لتوفر الآيس كريم.
- `availability.json`: ملف التوفر الذي تقرؤه صفحة العملاء.
- `omani-rial-symbol.png`: رمز الريال العُماني.

لا توجد صفحة أو وصلة إدارة منفصلة، لذلك لن يحدث تداخل بين رابط العملاء ورابط الإدارة.

## 1. رفع الموقع

1. أنشئ مستودع GitHub عامًا، مثل `pizzasto-order`.
2. ارفع محتويات هذه الحزمة إلى جذر المستودع.
3. افتح إعدادات المستودع ثم `Pages`.
4. اختر `Deploy from a branch`، ثم الفرع `main` والمجلد `/(root)`، وبعدها احفظ.
5. انتظر حتى يظهر رابط GitHub Pages.

مرجع GitHub الرسمي: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

إذا كان اسم المستخدم `USERNAME` واسم المستودع `pizzasto-order`، فرابط الموقع هو:

`https://USERNAME.github.io/pizzasto-order/`

## 2. فتح إدارة توفر الآيس كريم

1. افتح رابط العملاء العادي نفسه.
2. اكتب الرمز `2468` في خانة البحث أعلى قائمة الطعام.
3. ستفتح نافذة إدارة توفر الآيس كريم تلقائيًا، ولن يظهر الرمز كنتيجة بحث.

هذا الرمز يخفي مدخل الإدارة فقط؛ الحماية الفعلية للنشر هي رمز وصول GitHub.

## 3. إعداد صلاحية النشر

1. أنشئ **Fine-grained personal access token** من إعدادات حساب GitHub.
2. اجعل وصول الرمز إلى مستودع الموقع فقط.
3. امنحه صلاحية المستودع `Contents: Read and write` فقط.
4. افتح الإدارة بالرمز `2468`، وحدد الأنواع المتوفرة، والصق رمز GitHub ثم اضغط `حفظ ونشر توفر اليوم`.

مرجع GitHub الرسمي: https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens

رمز وصول GitHub لا يُحفظ في المتصفح ويُمسح من الحقل بعد نجاح النشر. تحفظ الصفحة اسم المستخدم واسم المستودع والفرع فقط لتسهيل التحديث التالي.

قد يستغرق ظهور تحديث التوفر في الموقع من دقيقة إلى ثلاث دقائق بعد النشر.
